# מיפוי שוק הכרמל

טופס מובייל לפעילים שעוברים בין הדוכנים, ומפה עם ייצוא לאקסל.
האתר הוא קבצים סטטיים (HTML/JS, בלי build). הנתונים נשמרים ב-**Google Sheets**, והתמונות בתיקייה ב-**Google Drive**, דרך סקריפט קטן של Google Apps Script שרץ על החשבון שלך.

```
index.html            הטופס (דיווח / להשלים / צומת)
map.html              מפה, סינון, ייצוא Excel ו-JSON
config.js             כתובת השרת (API_URL)
assets/               JS ו-CSS
data/addresses.json   כתובות רובע 5 (5,863 כתובות, 58 מהן ברחוב הכרמל)
apps_script/Code.gs   צד השרת (מדביקים ל-Apps Script)
scripts/build_data.py בונה מחדש את data/ מתוך הריפו kalpi-map
```

## מצב הדגמה

כש-`config.js` מכיל `API_URL: 'mock'` (ברירת המחדל, עד שמדביקים את ה-URL), כל קוד נכנס והנתונים נשמרים רק בדפדפן. כך אפשר לנסות את הכול לפני שמחברים את גוגל:

```bash
python3 -m http.server 8000
```

ואז לפתוח את http://localhost:8000.

## התקנה

**כבר מוכן בדרייב שלך** (תיקייה "מיפוי שוק הכרמל"):
- הגיליון "מיפוי שוק הכרמל - נתונים", עם הלשוניות `users`, `businesses` ו-`junctions`. בלשונית `users` יש קוד לאייל ו-10 קודים מוכנים לפעילים (כרגע לא פעילים).
- התיקייה "תמונות", שאליה נשמרות התמונות.
- ב-`apps_script/Code.gs` כבר כתובים ה-ID של הגיליון ושל התיקייה.

**נשאר לעשות פעם אחת (כ-3 דקות).** גוגל לא מאפשר ליצור את זה מבחוץ:
1. פותחים את הגיליון ובוחרים **Extensions → Apps Script**. מוחקים את מה שיש, מדביקים את כל `apps_script/Code.gs` ושומרים (Ctrl+S).
2. **Deploy → New deployment**, ובסוג (⚙️) בוחרים **Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**. זה לא חושף את הנתונים: כל בקשה חייבת קוד פעיל מהלשונית `users`.
   גוגל יבקש הרשאות (Advanced → Go to… → Allow). מעתיקים את ה-URL שמסתיים ב-`/exec`.
3. ב-`config.js` מחליפים את `'mock'` ב-URL, ומעלים לדומיין את `index.html`, `map.html`, `config.js`, `assets/` ו-`data/`.

### ניהול פעילים
בלשונית `users`, שורה לכל פעיל: **שם | קוד | פעיל** (TRUE/FALSE).
- כדי לצרף פעיל: משנים את "פעיל N" לשם שלו, מסמנים TRUE ושולחים לו את הקוד.
- לפעילים נוספים מוסיפים שורה עם קוד ארוך ולא צפוי, למשל 8 תווים אקראיים.
- כדי לחסום פעיל משנים את "פעיל" ל-FALSE. זה תופס מהבקשה הבאה שלו.
- השם שבעמודה הראשונה נרשם אוטומטית בעמודה "מילא/ה" של כל דיווח שהפעיל שולח.

### עדכון קוד השרת
אחרי שינוי ב-`Code.gs`: **Deploy → Manage deployments → ✏️ → Version: New version**. כך ה-URL נשאר אותו URL.

## איך זה עובד בשטח

- **מתחילים מעסק:** במסך הפתיחה בוחרים **"הוספת עסק חדש"** (יש עם מי לדבר) או **"הוספת עסק ריק"** (סגור עכשיו או סגור לגמרי).
  - בעסק ריק ממלאים רק בסטה/חנות, כתובת, שם וסוג (לא חובה), תמונה והערה.
  - הכתובת: רחוב (עם השלמה), מספר (הצד מוצג אוטומטית) ותיאור מיקום חופשי.
  - התמונה מצולמת ישר מהדף, בלחיצה על כפתור המצלמה.
- **בסוף כל טופס** יש שלושה כפתורים:
  - **שמור והמשך לעסק דומה:** הרחוב ו"מקושר ל-" נשמרים.
  - **שמור והמשך לעסק אחר:** טופס נקי.
  - **שמור והמשך לעסק ריק:** הרחוב נשמר.
- **ה-GPS** נשמר בפתיחת הטופס ובשמירה.
- **שדות חובה:** בעמוד **הגדרות** (`settings.html`, הקישור מופיע רק למנהלים) יש טבלה: השורות הן השדות, והעמודות הן "עסק חדש" ו"עסק ריק". לכל תא בוחרים חובה, רשות או לא מוצג, והשינוי חל על כל הפעילים.
  ברירת המחדל: **בעסק חדש** הכול חובה חוץ מתיאור מיקום, מקושר ל- והערה. **בעסק ריק** חובה בסטה/חנות, רחוב, מספר ותמונה.
  בשוכר/בעלים יש גם "לא יודע כרגע", ובמפה אפשר לסנן לפיו כדי לחזור ולתקן. שדה חובה שחסר מסומן באדום, והדף גולל אליו. מנהל מוגדר בעמודה "מנהל" בלשונית `users`.
- **שאלות לסוחר (רשות, רק בעסק חדש):** מאיפה הוא, איך הוא מגיע לשוק (עם הצעות, אפשר להקליד חופשי), והאם היה משתמש בשאטל (כן / לא). "מקושר ל-" נמצא מתחת לשם העסק.
- **"אחר":** כשבוחרים סוג עסק "אחר", נפתחת תיבה לפירוט.
- **מצלמה:** הצילום נפתח בתוך הדף במצלמה האחורית, ויש כפתור להחלפת מצלמה. אם הדפדפן לא מאפשר, נפתחת המצלמה של המכשיר. אפשר גם לבחור תמונה מהגלריה.
- **עדכון דיווח שנשלח:** בכרטיס העסק במפה יש "עדכון" לשוכר/בעלים ולהערה, וכפתור "עריכה מלאה בטופס". עדכון לא דורס את ה-GPS המקורי, ונרשם בעמודות "עודכן ע\"י" ו"עודכן".
- **להשלים:** רשימה של כל העסקים הריקים. לוחצים "השלמה", ונפתח טופס עסק חדש עם מה שכבר ידוע.
- **צמתים:** במפה (`map.html`) לוחצים **"סימון צמתים"**, אחר כך על המפה במקום הצומת, ומקלידים את שם הרחוב החוצה. לחיצה על צומת קיים מאפשרת למחוק אותו.
- **בלי קליטה:** הדיווח נשמר בטלפון, וליד שם הפעיל מופיע מונה "ממתינים לשליחה". השליחה נעשית אוטומטית כשהרשת חוזרת. שליחה כפולה לא יוצרת שורה כפולה.
- **מפה:** סמן לכל עסק: ירוק = מולא, כתום = ריק ולהשלים. ריבוע = עסק שהכתובת שלו לא ברשימה, ולכן הוא מסומן לפי ה-GPS. כמה עסקים באותה כתובת נפרשים מעט סביב הנקודה. לחיצה על סמן, או על שורה ברשימה, פותחת כרטיס עם כל הפרטים והתמונה. התמונה נטענת מהשרת, רק עם קוד פעיל.
  הרקע הוא צילום מסך מה-GIS העירוני (`assets/ortho-carmel.webp`), מעל צילום האוויר של Esri. אפשר לכבות אותו בכפתור השכבות.
  להחלפה בצילום חד יותר: `python3 scripts/georef_ortho.py IMAGE ../kalpi-map AX AY SCALE` מדפיס את הגבולות, ומעדכנים את `ORTHO` ב-`config.js`. יש סינון לפי סוג עסק, "מקושר ל-" וסוג מבנה, וייצוא לאקסל (לשוניות עסקים וצמתים) או ל-JSON.
  הגיליון עצמו בגוגל הוא גם קובץ האקסל: File → Download → xlsx.

## הערות

- **פרטיות:** המאגר מכיל שמות, טלפונים ותמונות. כל פעיל עם קוד יכול לראות את כל הנתונים במפה (צריך את זה בשביל רשימת "להשלים"). הגיליון והתיקייה בדרייב נשארים פרטיים שלך.
- **אחסון:** כל תמונה מוקטנת בטלפון לפני השליחה ל-2000 פיקסלים בצד הארוך, בערך 0.5–1MB. 400 תמונות הן עד כ-400MB.
- **הרחבת האזור:** `python3 scripts/build_data.py /path/to/kalpi-map`. תתי-הרובעים מוגדרים ב-`ROVA_ZONES`.
